Data Visualization

Chart types and visualization patterns for effective data presentation.

Line Chart

Used to display trends over time. Shows continuous data points connected by straight line segments.

  • Time-series data visualization
  • Trend analysis
  • Multiple series comparison

Bar Chart

Compares categorical data using rectangular bars with lengths proportional to the values.

  • Category comparison
  • Vertical and horizontal variants
  • Stacked and grouped options

Area Chart

Similar to line charts but with the area below the line filled with color, emphasizing volume.

  • Cumulative trends
  • Part-to-whole relationships over time
  • Stacked area for multiple categories

Scatter Plot

Displays values for two variables as points, showing relationship or correlation between them.

  • Correlation analysis
  • Outlier detection
  • Distribution patterns

Pie Chart

Circular statistical graphic divided into slices to illustrate numerical proportion.

  • Part-to-whole relationships
  • Percentage distribution
  • Limited to ~6 categories maximum

Donut Chart

Variation of pie chart with empty center, allowing for additional information display.

  • Cleaner visual than pie charts
  • Center space for totals or labels
  • Better for multiple small values
