# CanJet Dashboard and Pattern Library

An interactive web project that combines a customer satisfaction analytics dashboard with a reusable UI pattern library.

## Live Demo

- [Open the CanJet Dashboard](https://christianenogm.github.io/CanJet/dashboard.html)
- [Open the UI Pattern Library](https://christianenogm.github.io/CanJet/)

## Overview

This repository includes:

- A dashboard for exploring airline customer satisfaction data
- A UI pattern library that documents branding, colors, typography, layout, and chart examples
- Data visualizations built from CSV data

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- D3.js

## Project Structure

- `dashboard.html`: Customer satisfaction dashboard
- `index.html`: Pattern library and design documentation
- `scripts/`: Data service and chart modules
- `styles/`: Dashboard and component styling
- `data/`: Source dataset
- `images/`: Chart examples and visual assets
